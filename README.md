# Kazumi Android 32-bit tv版

本仓库基于上游 [Predidit/Kazumi](https://github.com/Predidit/Kazumi) 的 **Android 32 位电视版（`armeabi-v7a`）APK**。

> [!IMPORTANT]
> 本仓库并非官方仓库，仅用于提供 **Android 32 位兼容版本**。
>
>
> 如需完整功能，请优先使用上游官方版本：  
> https://github.com/Predidit/Kazumi

## 上游项目

- 上游仓库： https://github.com/Predidit/Kazumi
- 官方发布： https://github.com/Predidit/Kazumi/releases


## 下载

本仓库只存放代码，不提供apk的下载。需要自行封装。
