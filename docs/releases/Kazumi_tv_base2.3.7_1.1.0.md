## 相对 TV 1.0.0 的优化

- 播放控制栏隐藏时，按一次确定立即切换播放／暂停并显示控制栏；长按不重复切换。
- 历史记录上下切换保持整行焦点，左右分别进入播放和更多操作，修复上下往返后的焦点不一致。
- TV 操作设置中的桌面快捷键置灰只读，上下浏览、左键返回分类，避免误入快捷键录入。
- 设置侧栏在首尾停住，不再从“关于”溢出到内容区；滚动保持当前分类可见。
- 规则仓库的已安装规则支持遥控焦点，能够从“最近更新”继续进入列表。
- 规则管理和编辑器滚动后向上返回顶部控件，完整恢复蓝色介绍模块。
- 规则行可用右键选择更多、排序，左键反向返回；整行确定进入编辑。
- 确定排序按钮后，上下移动规则并保存，焦点跟随同一条规则；确定或返回只结束排序。保存期间不叠加请求，搜索、筛选、批量选择和更新期间禁止排序。普通版保留拖动排序。
- 新增历史记录、规则导航、排序异步保存、返回层级、设置边界和编辑器顶部恢复回归测试。
- 整理 README 排版和社区维护声明，保留上游全部感谢与版权说明。

## 安装与版本

Release 提供 `Kazumi_tv_base2.3.7_1.1.0-arm.apk` 和 `SHA256SUMS.txt`。APK 支持 ARM 32 位／64 位，独立包名 `com.predidit.kazumi.tv`，Android 版本名 `Kazumi_tv_base2.3.7_1.1.0`，构建号 `20307110`。

使用与上一版本相同的本机开发签名，可覆盖安装同签名 TV 版并保留数据；不是上游官方签名。无须卸载普通 Kazumi。本次尚未接入社区应用内更新，下载 APK 后侧载安装。

源码对应此 Release 的同名标签。构建：`./tools/build-tv.ps1 -TvVersion 1.1.0 -TvBuildNumber 20307110`。验证：`./tools/test-tv.ps1`。
