## 应用内更新接入

- 固定查询 `liuliuhong/Kazumi` 的最新正式 TV Release，使用 Android 构建号比较版本，禁止下载上游普通版。
- 设置支持启动检查开关与手动检查，关于页手动检查接入同一渠道；每天最多自动检查一次，播放及其他弹窗期间延后提示。
- 遥控更新界面显示当前／新版本、文件大小和可滚动更新说明，支持稍后提醒、跳过此版本、下载取消确认及恢复入口焦点。
- 关于页检查更新时保留按钮焦点，防止关闭更新弹窗后焦点跳到旁边的更新日志。
- 首次启动“添加规则”和规则仓库的 TV 列表统一为整行焦点，确定执行安装／更新；右侧按钮不再单独获得遥控焦点，安装中和已安装状态保留整行，避免从“开始使用”向上返回时落到无响应的焦点。
- 同时检查更新信息附件及 APK 的大小与 SHA-256。原生核对独立包名、实际版本、同一签名、系统版本和 CPU 架构，限制安装路径，禁止降级；启动安装器前再次复核。
- 用户确认后请求 Android 系统安装器，未获未知来源安装权限时提供授权入口，取消授权保留下载文件；不静默安装。
- 网络超时、限流、缺少附件、版本或哈希不一致明确报错，检查失败不会显示“已经是最新版”。
- 同一次应用运行中，设置与关于入口共享 5 分钟成功检查缓存，包括无需更新的结果；构建号／系统／ABI 变化或缓存到期后重新查询。限流时解析 `X-RateLimit-Reset` 和 `Retry-After`，显示本机时间的可重试时间，并在等待期内阻止重复检查；没有有效时间时至少等待 1 分钟。普通 403 不再误报限流。缓存随应用进程结束清除。

## 遥控焦点与滚动修复

- 所有设置详情共用顶部恢复逻辑：向上返回第一行控件时恢复完整介绍，补齐全局向上可见性滚动；预构建设置列表附近条目，避免滚出屏幕后无法导航回来。
- 管理追番同步的折叠账号输入框不参与焦点导航；番剧详情收起的头部与未选中的标签页同样排除焦点。
- 追番同步弹窗默认聚焦取消／关闭，打开期间保留入口按钮的可聚焦性。
- 推荐页行末右键进入回顶按钮，确认回顶后恢复顶部内容焦点。
- 番剧吐槽与制作人员拥有独立阅读焦点，长评论先逐段滚动，再进入下一条。详情列表可右键进入开始观看，左键恢复原条目；标签与关联卡片在行内保留左右导航，到行末再进入观看按钮。TV 的开始观看移至右上角固定工具栏，取消底部截断与浮动遮挡，列表保持完整高度。

- 播放选集侧栏的线路栏统一可聚焦，单线路也可查看；下拉菜单取得焦点，上下选择、确定实际切换当前集的线路，返回只关闭菜单，再返回关闭侧栏。新线路缺少当前集时从第一集开始；向上返回顶部控件时恢复完整标题与线路栏。

## 安装与发布约定

版本名 `Kazumi_tv_base2.3.7_1.2.0`，Android 构建号 `20307120`，包名 `com.predidit.kazumi.tv`。构建使用上一版相同的本机开发签名，可覆盖安装保留数据，不是上游官方签名。

1.0.0／1.1.0 没有此更新功能，必须手动安装一次接入版。

构建命令：`./tools/build-tv.ps1 -TvVersion 1.2.0 -TvBuildNumber 20307120`。

输出目录 `build/tv/Kazumi_tv_base2.3.7_1.2.0/` 包含：

- `Kazumi_tv_base2.3.7_1.2.0-arm.apk`
- `update.json`（明确的版本、构建号、包名、系统／ABI 要求、附件名、大小及 SHA-256）
- `SHA256SUMS.txt`

发布时先上传全部附件，核对 GitHub 附件记录与本地文件一致，再将正式 Release 设为最新版。后续版本必须递增构建号，继续保留同一签名。
