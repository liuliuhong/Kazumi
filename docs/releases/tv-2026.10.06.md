# Kazumi_tv_base2.3.7_1.0.0

原发布名称为“2026-10-06 社区兼容版”，现统一为 TV 1.0.0。新增同名源码标签指向原发布提交，保留历史 `tv-2026.10.06` 标签。此次仅调整发布名称与标签，原 APK、哈希、应用内版本 2.3.7 和 Android 构建号 20307 均不变。

## 本次发布

- 基于 2.3.7（20307），包含 2026-10-06 全部 TV 适配与各轮修复，完整列表见 [README](../../README.md#2026-10-06-全部改动列表)。
- 独立包名 `com.predidit.kazumi.tv`，电视入口、横屏、焦点提示，支持 ARM 32 位 / ARM 64 位。
- 遥控播放、快进快退、选集换集；返回按层级关闭控制栏与侧栏。
- 原生 TV 输入与取消处理；设置左右栏、下拉菜单、配色方案和追番焦点导航。
- 设置滑块按确认进入调整，左右调整，返回结束；上下保留导航。
- 离线下载分别选择播放或删除；评论支持遥控滚动；主侧栏上下到边界后停住。
- Bangumi 公开接口回退；弹幕 API 凭证可在设备配置，使用 Android Keystore 加密存储。
- MediaCodec 硬件解码、64 MiB 普通播放缓存、禁止普通版更新覆盖 TV 包。
- 附便携开发环境、构建脚本和 TV 组件回归测试。

## 安装与校验

下载 `Kazumi-TV-2.3.7-20261006-arm.apk` 并侧载到盒子。无需卸载普通 Kazumi；已安装本机同签名 TV 版可直接覆盖安装。当前 APK 使用本机开发签名，不是上游官方签名。保留这个签名的后续构建才能覆盖更新；不同签名构建不能直接覆盖。

SHA-256：`668dab8d8a10f2d1d90845c5cdd393511ab62d5443974b47adf3a75218bac1c2`。Release 同时提供 `SHA256SUMS.txt`。

源代码与此 Release 的标签对应；构建命令和环境说明见 README 与 `tools/`。

## 验证与已知限制

- 已在小米盒子 HyperOS 3.0.2.0 / Android 14 / 32 位 ARM 安装，并验证搜索、输入、播放和各主要焦点修复。
- 10 个 TV 组件测试通过，APK 包名、ABI 与签名校验通过。删除流程验证到确认弹窗并取消，未实际删除用户视频。
- 弹弹 play 需要使用者申请有效 AppId / AppSecret；源码及发布附件不提供上游私有凭证。没有有效凭证时弹幕不可用，实际来源还取决于接口收录。
- 源站可用性、音频输出及长时间播放稳定性仍需继续验证。完整 Windows 项目测试需要额外的原生 C++ 开发环境。
